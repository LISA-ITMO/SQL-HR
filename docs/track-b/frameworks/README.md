# КРМ для первого этапа B

[Исходная книга КРМ ИТМО 3.0](itmo-krm-3.0.xlsx) — нормативная основа для выбора ролей, компетенций, индикаторов и описаний уровней. Копия из исследовательской коллекции, без изменения содержимого.

Для знакомства откройте листы «Роли - определения и функции», «Роли-компетенции наглядно» и «Профессиональные». Подробные описания находятся также на остальных листах компетенций.

КРМ задаёт содержание ролей, но не готовую процедуру оценки кандидатов. Правила достаточности свидетельств, личного вклада и объединения оценок разрабатываем отдельно. Целевой уровень компетенции нельзя автоматически переносить на каждый индикатор. Готовый граф пререквизитов и категории обязательных/желательных требований КРМ не предоставляет.

В исследовательской коллекции есть также материалы МФТИ; они не входят в комплект первого этапа. Их уровни и индикаторы нельзя объединять с ИТМО без проверки соответствий.
